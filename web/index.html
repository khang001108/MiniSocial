Hướng dẫn cài đặt

Chỉ vài bước để bắt đầu trên điện thoại Java ME.

01 / TẢIChọn JAR hoặc JAD

Tải JAR trực tiếp. Nếu điện thoại hỗ trợ cài qua JAD, hãy lưu JAD cùng thư mục với JAR.

02 / CHUYỂNĐưa file vào Nokia

Dùng Bluetooth, USB hoặc thẻ nhớ. Mở JAR/JAD và làm theo trình cài đặt Java của điện thoại.

03 / KẾT NỐIĐăng nhập và chia sẻ

Mở MiniSocial, đăng ký hoặc đăng nhập. Cần kết nối mạng và máy chủ API đã cấu hình.

Lưu ý: Bộ cài hiện đặt API tại https://minisocial.xubi.org. Cần cấu hình DNS/HTTPS trước khi dùng đăng ký, chat hoặc đăng bài qua Internet. Tương thích chứng chỉ TLS trên Nokia đời cũ chưa được xác nhận.
